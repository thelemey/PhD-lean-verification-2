# PhD-lean-verification-2

Формализация диссертации Жасема Хамуда «Экстремальные значения инвариантов графа в некоторых классах графов».

- [Исправленный текст диссертации](docs/thesis_corrected.pdf). Семь положений на защиту приведены в § 1.3, на печатных страницах 6–8.
- [Полный граф в SVG](docs/dependency_graph.svg) и [векторный PDF с закладками](docs/dependency_graph.pdf) открываются в GitHub. В PDF есть обзор, семь положений с основаниями, семь глав и полный граф со всеми межглавными связями.
- [Интерактивный граф](docs/dependency_graph.html). Откройте HTML в браузере из копии репозитория. В карточках работают ссылки на страницы PDF и файлы Lean.
- [Приложенный граф сравнения редакций](docs/dependency_graph_original.html).

| № | Положение | Цель Lean |
|---|---|---|
| 1 | Формулы индексов Альбертсона и σ через степени хребта | [Trees.Claim1](lean/Thesis/Trees.lean) |
| 2 | Достижимые минимум и максимум irr по перестановкам степеней | [Trees.Claim2](lean/Thesis/Trees.lean) |

Каждая цель определена как предложение типа `Prop`. Её можно использовать как тип теоремы. Для деревьев берутся конечные простые графы на `Fin n`; условие `Realizes` связывает порядок и полные степени хребта с рёбрами графа. Для двудольных графов используется множество пар вершин двух долей (§ 5.1). Для бесконечных слов используется поток битов с заданными конечными префиксами.

## Сборка

Из корня репозитория, с установленным elan и Python 3. Для проверки файлов графа установите зависимости из scripts/requirements-graph.txt.

```sh
python3 -m pip install -r scripts/requirements-graph.txt
cd lean
lake exe cache get $(git grep -h '^import Mathlib' -- '*.lean' | awk '{print $2}' | sort -u)
lake build
cd ..
python3 scripts/graph.py --check --audit
```

## Как отметить доказательство в PR

Добавьте доказательство в модуль Lean и импортируйте модуль из `lean/Thesis.lean`. Для каждого полностью доказанного узла внесите запись в [реестр доказательств](docs/proofs.json) с полями `theorem` (полное имя теоремы) и `file` (путь относительно `lean/`). Ключ узла можно найти в данных графа. Выполните `python3 scripts/graph.py` и включите обновлённые HTML, SVG и PDF в тот же коммит. Для экспорта PDF нужны Cairo и шрифт DejaVu Sans с кириллицей. Для новой топологии генератору нужен Graphviz (`dot`).

Граф сохраняет золотую заливку семи положений. Красная рамка означает открытую цель, зелёная — доказанную. У остальных узлов статус виден и по заливке. Проверка PR сверяет HTML с реестром, проверяет тип каждой доказанной цели защиты и выводит аксиомы зарегистрированных доказательств. Для отдельно принятого результата литературы укажите источник при объявлении аксиомы.
